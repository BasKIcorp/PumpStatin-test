# Studio — визуальный редактор страниц (Figma-like)

Обновлено: 2026-06-15

## Внешний вид

Вкладка **«Страницы»** — полноэкранный тёмный редактор (`fixed`, справа от админ-сайдбара):

| Зона | Содержимое |
|------|------------|
| Верхняя панель | Выбор страницы ▾, вкладки Studio, Превью, Сохранить |
| Слева 240px | **Слои** / **Блоки** (вкладки как в Figma) |
| Центр | Точечная сетка `#1e1e1e`, артборд 1024px, зум внизу справа |
| Справа 260px | **Свойства** — страница или выбранный блок |

Цвета: акцент `#0d99ff`, панели `#2c2c2c`.

## Управление

| Действие | Жест |
|----------|------|
| Панорама | Колёсико |
| Зум | Ctrl + колёсико или виджет − / % / + |
| Рука | Space + drag, средняя кнопка |
| Обрезка блока | Выделить блок → перетащить полоску на стороне (или % в Свойствах) |
| Поворот | Кнопка ↻ над блоком (Shift — шаг 1°) |
| Размер | Угол правый нижний |
| Удалить блок | Delete |
| Снять выделение | Escape |

## Ключевые файлы

- `figma/StudioEditorTopBar.tsx`, `PageSelector.tsx`, `StudioLeftSidebar.tsx`
- `canvas/StudioCanvas.tsx` — сетка, артборд, FloatingZoom

- `pages/admin/AdminProfileStudio.tsx` — immersive mode для `activeTab === "pages"`
